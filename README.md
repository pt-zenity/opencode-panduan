# Panduan OpenCode Pentester — Bahasa Indonesia

Dokumentasi penggunaan **opencode-pentester** dalam Bahasa Indonesia.

## Berkas panduan

- `index.html` — panduan interaktif dengan tombol salin perintah.
- `docs/opencode-pentester-panduan-terpisah.pdf` — versi PDF.
- `docs/opencode-pentester-panduan-terpisah.docx` — versi Word yang dapat diedit.

## Penggunaan

Buka `index.html` melalui browser. Setiap perintah disajikan terpisah agar mudah dipahami dan disalin.

> Gunakan pengujian keamanan hanya pada sistem milik sendiri atau dengan izin tertulis.

Sumber proyek: https://github.com/humaidhahm/opencode-pentester
